# 나라장터 공고 위반 탐지

나라장터 입찰공고를 분석하여 법령상 위반 가능성이 있는 항목을 자동으로 탐지하는 프로젝트입니다.

LLM을 활용해 공고문을 분석하고, 24개의 법적 판단 항목에 대해 위반 여부를 분류합니다.

단순한 LLM 판단뿐만 아니라 법령에 명시된 조건을 활용한 규칙 기반 판정과 결과 검증 과정을 함께 사용합니다.

공고문 입력 → 전처리 및 항목 분류 → LLM 분석 → 규칙 기반 검증 → 최종 위반 여부 판정의 과정을 거쳐 결과를 생성합니다.

## 주요 기능

- 나라장터 입찰공고 분석
- 24개 법적 위반 항목 자동 판정
- LLM 기반 문서 분석
- 법령 기반 규칙 판정
- 판정 근거문구 추출 및 검증
- 결과 평가 및 성능 분석
- 등급 기반 판정 및 threshold 조정

## 목적

대량의 나라장터 입찰공고를 자동으로 분석하여
법령 위반 가능성이 있는 공고를 효율적으로 찾아내는 것을 목표로 합니다.
