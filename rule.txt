2. 대회 규칙
1) 고정 LLM 기반 파이프라인 개발 대회
본 대회는 지정된 고정 LLM을 기반으로 추론 파이프라인(전처리·프롬프트 구성·검색·후처리 등)을 개발하는 대회입니다.
고정 LLM : google/gemma-4-26B-A4B-it (리비전 4d7ae4984b7db7de8f8457170b3f1a419ee76d52). 전 참가자가 평가 서버에 준비된 동일한 모델을 사용하며, 보조 임베딩 모델 BAAI/bge-m3 (리비전 5617a9f61b028005a4858fdac845db406aefb181)가 함께 제공됩니다.
두 모델은 평가 서버에 미리 준비되어 있으므로 참가자가 모델을 제출할 필요가 없으며, 제출해서도 안 됩니다. 제출물은 추론 코드(및 RAG 인덱스 등 정적 자산)만으로 구성합니다(평가 탭 참조).
고정 LLM에 대한 파인튜닝(LoRA·QLoRA 등 어댑터 학습 포함) 및 모델 가중치·어댑터의 제출·로드는 허용되지 않습니다. 고정 LLM과 보조 임베딩 모델 외에, 참가자가 학습시킨 모델 가중치를 위반 여부 판정에 사용하는 것은 허용되지 않습니다(분류기·회귀 모델·추가 임베딩 모델 등 종류를 불문). model/에는 RAG 검색 인덱스 등 정적 자산만 포함할 수 있습니다.
제출된 추론 코드는 평가 데이터의 각 공고에 대해 고정 LLM 정상 호출을 1회 이상 수행해야 합니다. 정상 호출이란 해당 공고의 내용을 포함한 프롬프트로 고정 LLM을 호출하여 정상 응답을 받는 것을 말합니다. 모델 호출이 없거나 공고 내용과 무관한 호출만 있는 제출물은 제출 요건 미충족으로 무효 처리될 수 있습니다. 모델 출력에 대한 후처리·규칙 기반 보정은 자유롭게 허용됩니다.
로컬 개발 환경(GPU·런타임·정밀도)은 자유입니다. 평가 탭의 채점 환경 명세는 서버 동작 재현을 위한 정보이며 개발 환경에 대한 요구사항이 아닙니다.


2) 외부 데이터 사용 금지 및 자가 라벨링 허용
학습·검증·추론 파이프라인과 제출물에는 대회에서 제공하는 데이터와 자료만 활용할 수 있습니다. 혼동을 줄이기 위해 허용/금지 범위를 아래와 같이 명시합니다.

✅ 허용되는 것
대회 제공 데이터·자료의 자유로운 활용 — 무라벨 20,000건, dev 200건(라벨 포함), data/ 폴더(항목표·법령패키지 등)를 학습·검증·검색·후처리 등 어떤 용도로든 사용 가능
자가 라벨링 전면 허용 — 제공된 무라벨 데이터에 참가자가 직접 라벨을 생성하여 학습·검증·검색 사례집·후처리 튜닝 등에 자유롭게 활용. 라벨 생성 방법(수작업·규칙 기반·모델 기반 등)에 제한 없음
라벨 생성 단계에 한해 외부 LLM(상용 API 포함) 사용 허용 — 단, 외부 LLM에는 대회 제공 자료만 입력할 수 있음
공개 오픈소스 라이브러리의 사용(requirements.txt를 통한 pip 설치) — 단, 라이브러리에 데이터 자산을 동봉하는 우회 반입은 금지(아래 참조)
모델 출력에 대한 후처리·규칙 기반 보정
본 대회 코드 공유 게시판에 전체 공개된 참가자 생성 자료(라벨·가공 데이터 등)의 활용
❌ 금지되는 것
외부 데이터의 수집·활용 일체 — 나라장터·공공데이터 API·웹 크롤링 등 외부 경로로 입찰공고 원문·메타데이터·라벨·정답성 정보를 추가 수집하여 활용하는 행위
배포 자료를 공개 원문과 링크·재수집·대조하여 익명화된 식별자(기관명·공고번호 등)를 복원하는 행위
외부 LLM의 웹 검색·외부 문서 결합 기능을 이용한 원문 조회·외부 데이터 취득(라벨 생성 단계 포함)
제출되는 추론 코드에서의 외부 LLM·외부 API 호출
제공 자료 외의 입찰공고·법령·라벨 등 데이터 자산을 pip 패키지 동봉, model/ 폴더 동봉 등 우회 경로로 평가 서버에 반입하는 행위
참가자가 생성한 라벨·가공 데이터의 특정 팀 간 사적 공유 — 공유는 본 대회 코드 공유 게시판을 통한 전체 공개만 허용
판정 기준은 배포된 법령 패키지(법령·행정규칙 전문 및 중소벤처기업부 고시 제2025-96호(2025. 8. 29.))의 스냅샷으로 고정되며, 채점도 이 스냅샷을 기준으로 합니다. 대회 기간 중의 법령 개정은 반영되지 않습니다.
법령 공부 등 개인적인 배경지식 습득을 제한하는 것은 아니나, 파이프라인·제출물에 결합하는 법령 자료는 배포된 법령 패키지를 사용해야 하며 판정·채점 기준 역시 이 스냅샷입니다.


3) 재현 가능성 및 출처 명시 의무
수상팀의 결과물은 대회에서 제공한 자료와 제출 자료만으로 재현이 가능해야 하며, 재현이 불가능한 경우 수상이 취소될 수 있습니다.
자가 라벨링을 사용한 경우, 라벨 생성 코드·프롬프트·절차도 재현 대상에 포함됩니다. 외부 LLM으로 생성한 라벨은 생성 코드·프롬프트·사용 모델(버전) 기록과 생성된 라벨 데이터의 제출로 재현을 갈음하며, 상용 API의 비결정성으로 인한 재실행 출력 차이는 문제 삼지 않습니다.
2차 평가 자료 제출 시 결과물 산출에 사용된 모든 요소에 대한 출처를 명확하게 기술할 수 있어야 합니다.


4) 비공개 평가 데이터를 활용한 추가 학습 금지

제출하는 추론 코드에서는 예측을 위한 전처리·후처리 및 추론 과정은 자유롭게 구성할 수 있습니다.
다만, 비공개 평가 데이터셋을 활용한 추가 학습, 모델 튜닝, Pseudo-Labeling 등 모델이나 규칙을 갱신하거나 학습에 활용하는 행위는 허용되지 않습니다.


5) 비공개 평가 데이터의 공고 단위 독립 예측 원칙

비공개 평가 데이터의 각 공고 샘플은 서로 독립적으로 예측해야 합니다.
허용 : 하나의 공고 샘플 내 문서(공고문·첨부)를 분할하여 추론하고, 결과를 종합하는 방식은 허용됩니다.
금지 : 다른 공고 샘플의 정보·예측값·통계 등을 활용하여 예측값을 생성하거나 보정하는 방식은 허용되지 않습니다.


3. 2차 평가 자료 제출 규칙
대회 종료 후 2차 평가 대상자는 안내되는 양식에 맞추어 2차 평가 자료를 dacon@dacon.io 메일로 기한 내에 제출
제출 파일 목록 및 세부 양식은 2차 평가 진출팀에 별도 안내됩니다.
🔹 리더보드 점수 재현이 가능한 코드 및 실행 방법 (자가 라벨링에 사용한 라벨 생성 코드·프롬프트 포함)

🔹 결과물 산출에 사용된 요소(모델·도구·자료)의 출처 명세

🔹 팀 구성원 정보 : 팀 구성원들의 '성명/생년월일/성별/현재 소속' 기재



4. 유의 사항
1일 최대 제출 횟수 : 1회
사용 가능 언어 : Python
모든 csv 형식의 데이터와 제출 파일은 UTF-8 인코딩을 적용합니다.
대회 종료 시점에 확정되는 Private 리더보드는 최종 순위가 아니며 2차 평가와 검증 이후 최종 수상자가 결정됩니다.
코드 제출 기능을 악용한 평가 데이터셋 유출 시도 등의 사항이 발견되는 경우 즉시 실격에 해당합니다.
데이콘은 부정 제출 행위를 금지하고 있으며 데이콘 대회 부정 제출 이력이 있는 경우 평가가 제한됩니다. 자세한 사항은 [부정 제출 정책]을 참고해 주시기 바랍니다.
